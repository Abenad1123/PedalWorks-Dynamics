# PedalWorks Dynamics: Bicycle Shop Management System

An Information Management Project for **BSIT-2B-T**, Technological University of the Philippines – Taguig.

## Project Description
A comprehensive e-commerce and management solution designed to streamline the daily operations of a bicycle shop. It integrates an online storefront for customer purchases, inventory tracking, service request handling, and basic financial reporting.

## Technology Stack
- **Environment**: XAMPP (Apache, MySQL)
- **Backend**: PHP 8.x
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Styling**: Custom Glassmorphism UI & Bootstrap 5
- **Icons**: Font Awesome 6
- **Database**: MySQL (`pedalworks_db`)

## Design Architecture
- **Theme**: Mountain, Trail & Outdoor Adventure
- **Visual Style**: Multi-layered Glassmorphism with `backdrop-filter: blur()`, specular borders, and subtle topographic contour motifs.
- **Palette**: Nature-inspired tones:
  - Deep Pine & Evergreen (`#07110c`, `#0c1b14`, `#12271d`, `#183427`)
  - Moss Green & Sage Foliage (`#2e5f48`, `#478164`, `#72a88d`, `#b8d8c8`)
  - Trail Terracotta & Ridge Amber accents (`#d16629`, `#e5793a`, `#f59b58`)
- **Homepage Assets**: Clean, responsive placeholder graphics and image containers.
